# 小邓的数据库

一个简单易用的数据管理系统，支持数据添加、编辑、删除、分类管理和图片上传功能。

## 功能特点

- 用户登录系统（管理员和普通用户）
- 数据添加、编辑和删除
- 分类管理（添加、编辑、删除分类）
- 图片上传和预览
- 数据搜索和筛选
- 数据导出（JSON和CSV格式）

## 部署到GitHub Pages

1. 在GitHub上创建一个新的仓库
2. 将所有文件上传到仓库
3. 在仓库设置中启用GitHub Pages
4. 访问 `https://你的用户名.github.io/仓库名` 查看网站

## 使用说明

### 默认账户

- 管理员：用户名 `admin`，密码 `123456`
- 普通用户：用户名 `user`，密码 `123456`

### 数据存储

所有数据存储在浏览器的本地存储中，清除浏览器数据会导致数据丢失。
